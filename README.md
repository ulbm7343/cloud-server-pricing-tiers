## 先给个价格锚点：一年大概分三档

**百元档（100～300 元/年）** 是入门建站和练手区。国内大厂的入门机型常年把首年促销价压在几十到一百元出头，比如常见的轻量应用服务器 2 核 2G 秒杀价 38 元/年、ECS 经济型 2 核 2G 约 99 元/年，腾讯云轻量的入门档也差不多在百元上下。这些价格看着香，但要留意两点：秒杀款要抢、有场次限制；促销价基本只覆盖第一年。

**三五百元档（300～600 元/年）** 是个人和小团队的主流选择。2 核 4G 到 4 核 4G，配上还算像样的带宽，能撑住一个正常访问量的博客、企业官网或者小程序后端。

**千元以上（1000～3000 元/年）** 通常是为了三样东西之一：更大的带宽、更高的防护、或者独立公网 IP。如果你要做下载站、大流量业务，或者国内机房要 100G 级别的高防，预算基本落在这里。

海外机房是个变量。香港、美国、日本这类地区不用备案，但线路质量差异极大，同配置价格能差一倍——光看 CPU 核数和内存挑机器，在海外这块几乎一定会踩坑。

## 影响年付价格的四个变量，比“配置表”更值得看

**第一，CPU 型号比核数重要。** 同样是 2 核 4G，跑在 E5 v2 上的和跑在 EPYC 7A23、Ryzen 9950X 上的，单核性能差距能到两三倍。开 Minecraft 服务器、跑 PHP 动态站这类吃单核的场景，核数多不等于跑得顺。

**第二，带宽有两种，别混着算。** “大带宽 + 限流量”和“小带宽 + 不限流量”是两种完全不同的计费思路。前者适合有明确流量峰值的场景，用不完的流量有的厂商还能按月叠加结转；后者适合长期稳定跑、但流量不大的站点。流量超了会限速，想恢复高速得单独买流量包。

**第三，硬盘和 IP 往往是额外项。** 大多数入门套餐默认给 30GB 系统盘，扩容按 GB 计费；独立公网 IP 一般也是单独加购，普通 IP 常见价格在 5 元/月/个这个量级，高防 IP 另算。这部分没算进“套餐价”里，是年付预算最容易超支的地方。

**第四，付款周期直接挂钩折扣。** 这是省钱的核心机制，下面单独说。
